# Triage 标签

工程技能按五个规范角色说话，本文件把它们映射到本仓库 issue tracker 里实际使用的标签字符串。

| 规范角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估 |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已写清，可交给无人值守 agent |
| `ready-for-human` | `ready-for-human` | 需要人来做 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色时（如「打上 AFK-ready 标签」），用上表右列的实际字符串。

分类角色 `bug` 与 `enhancement` 用 GitHub 自带标签，不另建。

要换词表，直接改右列。
